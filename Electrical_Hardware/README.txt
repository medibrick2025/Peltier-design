# PCB Ordering Guide

This folder contains the PCB manufacturing files for the Peltier hardware system.  

## PCB File Locations

```text
Electrical_Hardware/12V_PCB/SMD_PCB/
Electrical_Hardware/48V_PCB/SMD_PCB_HV/
Electrical_Hardware/Faceplate_PCB/
```

## How to Order the PCB

1. Download this repository from GitHub by clicking **Code → Download ZIP**, or clone it with Git.  

2. Open the `Electrical_Hardware` folder and choose the PCB folder you want to order.  

3. Compress the selected PCB folder into a `.zip` file.  

```text
12V_PCB/SMD_PCB/       →  SMD_PCB.zip
48V_PCB/SMD_PCB_HV/    →  SMD_PCB_HV.zip
Faceplate_PCB/         →  Faceplate_PCB.zip
```

4. Upload the `.zip` file to PCBWay as the Gerber file package.  

5. Check the PCB preview, confirm the order settings, and submit the order.  

PCBWay will review the files before manufacturing.
